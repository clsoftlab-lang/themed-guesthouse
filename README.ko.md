# 테마 게스트하우스

젊은 여행자·관광객을 위한 **테마 게스트하우스 예약 데모** 사이트입니다. 빌드 도구 없이 순수
HTML + CSS + ES 모듈 자바스크립트로 만들었고, GitHub Pages 에 그대로 배포됩니다
(루트에 `index.html`, 상대 경로만 사용). 루프탑 온천·감성 카페형·파티형·반려동물·여성전용·서프
비치 등 6개 테마, 10개 지역, 가상 숙소 24곳(룸 73개)을 담았습니다.

**라이브 데모: https://clsoftlab-lang.github.io/themed-guesthouse/**

## 주요 기능

- **탐색/검색/필터/정렬** — 테마 칩, 키워드 검색, 지역·최소인원·편의시설·최대가격(슬라이더), 추천/가격/평점 정렬.
- **숙소 상세** — 테마 소개, 룸 종류, 편의시설, 인라인 SVG 갤러리 4장, 리뷰·평균 평점, 위치 스키매틱(개념도).
- **예약 흐름** — 날짜 범위 선택 → 기존 예약과 겹침 확인(재고/가용성) → 인원·룸 수 → 실시간 요금 계산 → 모의 결제 → 예약 확정(예약번호 발급).
- **가용성/요금 엔진** (`pricing.js`, 순수 함수 + 단위 테스트) — `총액 = Σ(1박요금 + 주말/성수기 할증) × 박수 × 룸 + 청소비 + 서비스료`. 주말(금·토) +15%, 성수기 +25%, 청소비 15,000원/룸, 서비스료 5%. 가용성은 기간이 겹치는 기존 예약을 룸별 재고와 비교합니다.
- **내 예약 / 위시리스트 / 테마별 큐레이션** — `localStorage` 저장.
- **반응형 + 라이트/다크**(`prefers-color-scheme`), 한국어 UI, 인라인 SVG 아트만 사용(바이너리 없음).

## 🤖 AI 기능 (API 연동)

앱의 실제 숙소·테마 데이터를 재사용하는 AI 기능 3종을 UI 에 연결했습니다:

1. **AI 여행 컨시어지 챗봇** (`#/ai`) — 지역·분위기·예산으로 숙소 추천.
2. **테마 추천** (`#/ai`) — 여행 성향을 6개 테마 중 하나로 매칭.
3. **주변 여행 코스 생성** (숙소 상세 페이지) — 선택한 숙소 기준 1일 여행 코스 생성.

**데모 = mock (기본값).** `ai/config.js` 의 `AI_ENDPOINT` 가 비어 있으면, 프론트가 브라우저 안에서
결정론적 한국어 MockProvider 로 답합니다 — 네트워크·API 키 전혀 없음. 별도 설정 없이 AI 가 바로 동작합니다.

**실제 Claude 켜기:** [`server/`](./server/README.md) 백엔드 프록시를 띄운 뒤 프론트가 그 주소를 보게 합니다.

```bash
cd server
npm install                 # @anthropic-ai/sdk
cp .env.example .env        # .env 에 실제 ANTHROPIC_API_KEY 입력
npm run dev                 # http://localhost:8787 실행
```

그다음 `ai/config.js`:

```js
export const AI_ENDPOINT = "http://localhost:8787/api/ai";
```

프록시는 모델 **`claude-opus-5`** (`messages.stream`, `max_tokens: 2048`,
`thinking: { type: "adaptive" }`) 로 호출하고 응답을 스트리밍합니다.

> **🔒 API 키는 서버에서만.** `ANTHROPIC_API_KEY` 는 **오직** `server/` 백엔드(환경변수)에만 두며,
> 브라우저·프론트엔드·저장소에는 **절대** 넣지 않습니다. `.env` 는 git 제외 처리되고, CI 는 서버를
> 설치·실행하지 않습니다. 프록시가 존재하는 이유가 바로 이것입니다.

## 로컬 실행

```bash
cd themed-guesthouse
python -m http.server 9002
# http://localhost:9002 접속
```

ES 모듈은 `file://` 이 아닌 HTTP 로 열어야 합니다.

## 검증

```bash
node check.mjs   # JSON 파싱 + 전 JS node --check + index.html 컨테이너 + 엔진 단위 테스트
```

`.github/workflows/ci.yml` 에서 동일 검증을 수행합니다.

## 데모 모드 경계 (중요)

- **모든 숙소·룸·리뷰·가격은 가상입니다. 실제 업소·상표 아님.**
- **결제는 전부 모의입니다. 결제 게이트웨이·카드 수집 없음. 실제 카드 정보를 입력하지 마세요.**
- **상태는 브라우저 `localStorage` 에만 저장되며 실제 DB 가 아닙니다.** 브라우저별로 남고, 지워질 수 있으며, 동기화되지 않습니다.
- **계정·로그인·개인정보 수집 없음.**
- **실제 서비스라면 백엔드+DB, 실 재고·채널 연동, 결제사, 인증, 이메일/SMS 확정, 관리자 도구가 추가되어야 합니다.**
